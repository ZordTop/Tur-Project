# Tur-Project
Я не знаю че тут писать. Вообщем будем работать, сайт делать. Сайт посвященный туристической теме, будет предоставлять пользователям список туров, содержащие: рейсы, проживание, трансферы. 


# Cтруктура файлов проекта
Tur-Project/
├── public/                   # Всё, что видит браузер (стили, картинки, клиентский JS)
│   ├── css/                  # Стили (style.css)
│   ├── js/                   # Скрипты для анимаций и кнопок на странице
│   └── images/               # Картинки сайта (логотип, баннеры, фото туров)
├── views/                    # HTML-шаблоны страниц (например, index.ejs, tour.ejs)
├── routes/                   # Маршруты сайта (какой код запускать при переходе по ссылкам)
├── server.js                 # Главный файл, который запускает сервер
├── package.json              # Список твоих JS-библиотек (Express и т.д.)
├── .gitignore                # Игнорируемые файлы (сюда обязательно пишем node_modules)
├── Dockerfile                # Инструкция упаковки твоего Node.js сайта в контейнер
├── docker-compose.yml        # Запуск сайта и базы данных одной командой
└── README.md                 # Описание проекта для GitHub
